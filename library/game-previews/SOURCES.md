# Game preview footage

Clips use the catalog game ID as the filename. Built-in clips are recordings of the matching games under the repository’s game template directory. Community clips are recordings of the published game or short excerpts from the credited public post, as listed below.

Hover clips are short, silent H.264 files with the MP4 metadata at the start. Landscape clips use up to 864 × 486 pixels and portrait clips use up to 486 × 864 pixels. Lower-resolution recordings retain their native detail. The gallery requests a clip when the pointer settles on its card. Draft MP4s play from the source checkout in Studio development. The existing Prepare and merge PR workflow records their immutable public URLs in the repository media registry. Release builds load those clips on hover and keep their bytes outside the install package.

Start each clip during visible gameplay. Review frames near the start, middle, and end of the exported MP4 for action, framing, and unintended letterboxing. For new browser captures, check frame pacing during input and animation. Keep the full controls or board in view when cropping encoded borders.
